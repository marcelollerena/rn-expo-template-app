# App Context

This folder holds **product context** for the app being built from this template.

Anything placed here is treated as background context for Claude: read it before
implementing features so decisions align with the product's intent.

## What goes here

- `prd.md` — the product requirements document (start from the template below).
- Any general context: domain overview, target users, business rules, third-party
  integrations, design references, or links to external specs.

## What does NOT go here

- Implementation specs for individual features. Those live in
  `docs/specs/features/<feature>/spec.md` (see "Specification Location" in
  `.claude/CLAUDE.md`).

## Getting started

1. Copy or rename `prd.md` and fill it in for your product.
2. Add any extra context files as needed.
3. Keep these documents up to date as the product evolves.
